# Every cell `zig build test-libs` would not run at all, because the member's
# `botopink.json` declares a `"targets"` list that excludes the target. One
# cell per line:
#
#   <lib> <target> <n-failed> <owner> <reason…>
#
# A restriction is an opt-out from the gate, and an opt-out with no line here
# is refused. `test-libs.sh` passes `--include-unsupported` to the runner, so
# every restricted cell RUNS on every gate, and its measured failed count is
# compared with `<n-failed>`.
#
# `<n-failed>` is the number of FAILING TESTS the cell has, or the token
# `build` when the cell does not compile at all — no test ran, so it has no
# count, and reading that as "0 failed" is exactly the blindness this file
# closes. Writing a line is a MEASUREMENT: run the cell
# (`zig build test-libs -- --lib <lib> --target <target>`) and copy what it
# prints. Never a guess.
#
# Only the FAILED count is pinned, never the passed one. A library that adds a
# green test moves nothing here, so an ordinary library commit never has to
# touch this repository — that is what makes a gate shared by seven fronts
# livable.
#
# The gate is strict in BOTH directions:
#
#   · a restricted cell with no line here      → FAIL. A new restriction has to
#                                                 be measured before it lands.
#   · a line whose member no longer restricts
#     that target                              → FAIL. Delete the line; the
#                                                 cell became an ordinary
#                                                 assert. (On an unfiltered
#                                                 run, a line with no cell at
#                                                 all is stale too.)
#   · a count that moved, UP or DOWN           → FAIL. Up is a regression; down
#                                                 is a fix, and it is banked by
#                                                 editing the number here in the
#                                                 same commit.
#
# There is no warning row and no flag that turns a line into a warning
# (decision 67): fail beats warn.
#
# `<owner>` is the front that owns the member's `targets` array, taken from
# `specs/1.0.10-beta/fronts.md` — the front that will delete the line by
# widening the array, not whoever measured it.
#
# A restricted cell never consults `known-red-libs.txt`: its verdict is this
# file's, and only this file's.
#
# Measured 2026-09-21 against botopink-lang ef2604af, with each library
# checkout at its own `feat` tip, by `botopink-lib-test --json
# --include-unsupported`. 18 cells, 17 members.
