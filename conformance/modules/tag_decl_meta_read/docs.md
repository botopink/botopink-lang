# tag_decl_meta_read

The reference text this cell shows (from `conformance/docs.md`, § A tag is a `@Decl` (decision 302)):

> In the annotation, `decl.attr(name)` is a static attribute as written (`null`
> when the tag has none, and on every declaration) and `decl.component` the
> component's own `@Decl` (`null` on an element). The template body reads the
> meta back by type, `d.meta(T)` (`?T`).
