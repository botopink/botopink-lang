# package_module_namespace

A dependency's module imported as a namespace is read as a module of the package is, on every target: `shapes.Pt` written as a type, `shapes.Pt(…)` and `shapes.origin()` called, and `shapes.shift` a function value bound by `val` and passed — `Pt(x: 1, y: 1)`, `3`, `2`, `5`.
