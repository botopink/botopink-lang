# fs_error_message

The reference text this cell shows (from `conformance/docs.md`, § The file system, `io.fs`):

> `FsError.message()` is the error's text, one per variant and the same on every target: `not found: <path>`,
> `permission denied: <path>`, `is a directory: <path>`, `not a directory: <path>`, `already exists: <path>`,
> `not UTF-8: <path> at byte <offset>` and `<path>: <message>` for `Other` (decision 563).
