# marker_words_before_brace

The reference text this cell shows (from `conformance/docs.md`, § Effects — Body markers):

> `{ async`, `{ iter`, `{ component` always open a lambda, and before a brace
> the words are names: `async { … }` is always the block (decision 523) and
> `iter loop { … }` the loop (125), whatever the body starts with, and a
> function named `iter` or `component` takes a trailing lambda as any function
> does.
