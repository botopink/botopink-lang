# marker_fn_without_return_type

The reference text this cell shows (from `conformance/docs.md`, § Effects — Body markers):

> A marker whose return type is not its wrapper is `marker-type-mismatch` at
> the marker; a marked function with no return type is the same refusal, its
> caption naming the return type to write — every function is typed (decisions
> 583, 584 (3)); a declaration without a body takes no marker
> (`marker-on-declaration`) — its return type alone says what it answers.
