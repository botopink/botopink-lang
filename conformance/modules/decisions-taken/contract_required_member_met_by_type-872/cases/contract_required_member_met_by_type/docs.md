# contract_required_member_met_by_type

Decision 872 (1), (2): a contract's required member the type already has is met by the type's own method —
`string`'s `slice` for `StringShout implement Shout for string {}`, a record's `label` for a block in its
module — and `string`'s `slice` answers the contract's `default fn`. The program runs.
