# generic_fn_value_takes_shape

A generic function that writes its `T` as text, named as a value, writes an `f64` with its decimal part on every
target: handed to a host callback (`xs.map(show)`, whose JavaScript `map` passes the index and the array after the
element) and to a function of the program. On commonJS the value is an arrow of the function's own arity that hands
the body the print shape of the type this use binds.
