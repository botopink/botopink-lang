# place_numbered_in_component_body

Decision 821: the calls answering a component are numbered within the nearest `component` body, a
lambda written in it counting with it, the item's counter that body's; a plain function's stamp is
overwritten by the call written in the body (821 (2)); a function named as a value is numbered where
written (821 (3)). Nothing is made again on the second render.
