# hand_written_twin_name_is_free

The names the compiler writes beside a person's (decision 836) live in its reserved space (decision 805 (6)):
a function with a value-or-type parameter (decision 297) gains its type form `__bp_<f>__type`, an enum's
section is the inner enum `Bp__<Enum>__<Section>`, and a function whose `@embed` reads a `comptime`
parameter `p` (decision 519) takes the `Asset` through the parameter `__bp_embed_<p>`. A hand-written
`pick__type`, `__Color__Warm` or `__embed_path` is an ordinary name beside them, on every target.
