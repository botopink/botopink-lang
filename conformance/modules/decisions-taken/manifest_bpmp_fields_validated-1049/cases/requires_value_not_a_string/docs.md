# requires_value_not_a_string

The reference text this case shows (from `conformance/docs.md`, § The manifest schema — `botopink.json`):

> `"botopink"` is a string, the compiler-version constraint; `"requires"` is an object of
> `<name>` to a constraint string, each name an entry of `"dependencies"`. A wrong shape is
> refused at the key, `manifest-unknown-field` aside, as the other manifest refusals are.
