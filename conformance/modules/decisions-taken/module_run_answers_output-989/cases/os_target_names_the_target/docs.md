# os_target_names_the_target

The reference text this cell shows (from `conformance/docs.md`, § The command line, `io.stdin`, `io.terminal` and
`io.process`):

> `io.os.target()` is the target the program runs on — `commonJS`, `erlang`, `beam` or `wasm`, each target's own
> constant (decision 989 (7)). It is read when the program runs, never at build.
