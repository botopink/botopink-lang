# external_std_prefix_refused_everywhere

The reference text this cell shows (from `conformance/docs.md`, § Host bindings):

> **A prefixed string is no binding** (decisions 305, 481, 847). The four
> prefixes — `fn:`, `op:`, `wasi:`, `std:` — are refused in a template on every
> variant and every target, `std:` included, naming the labelled cell to write
> instead (`.Wasm(std: "hash.contentHash")`).
