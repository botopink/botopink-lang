# dict_float_value

The reference text this cell shows (from `conformance/docs.md`, § Indexing and slicing):

> A `Dict`'s value is any type, a float or a 64-bit integer included: `insert` keeps the value whole and
> `at` (and so `d["k"]`) answers it as the `?V` it is — present, absent or overwritten — on every target.
