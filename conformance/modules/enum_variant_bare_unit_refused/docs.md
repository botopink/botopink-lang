# enum_variant_bare_unit_refused

The reference text this cell shows (from `conformance/docs.md`, § type — enums):

> A bare unit variant in expression position (`val k: Kind = Element;`) is refused too, also
> where the name is another enum's variant (the prelude's `DeclKind.Element`): the refusal
> names both spellings and `.Element` is `Kind`'s where a `Kind` is expected (decision 587).
