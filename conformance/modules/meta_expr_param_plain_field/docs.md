# meta_expr_param_plain_field

Decision 576 (12): a meta record's field written `@Expr<T>` (370 (1)) is written `T`: it holds a tree when filled from an `expr` (575 (4)'s tree rule), no field modifier. The refusal `decorator-meta-expr-arg` of an `expr` handed to a plain field is gone: `Entity(table: table)` holds the annotation's `"cities"`.
