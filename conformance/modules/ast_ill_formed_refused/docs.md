> Decision 625 (2) — a tree that is no code is refused at the `ast` call,
> naming the node (`ast-ill-formed`): a record that is no `Node`, an `Arg`
> outside a `Call`, a `Lit` holding a `syntax` value, a name that is no
> identifier, an operator the language has not, and a `Name` nothing binds
> where the tree is spliced.
