# template_hole_typed_at_caller

The reference text this cell shows (from `conformance/docs.md`, § Template functions): **A hole is the template's** (decision 577 (1), (5), 14s8-a (e)) — the template finds `${…}` in `compiler.text(q)` and splices each hole's expression into the code it builds, where it is typed in the caller's scope; a mistyped hole is refused at the hole.
