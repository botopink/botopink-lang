# associated_fn_value_answers_record

The record such a value's call answers is read by its field, for a member a
decorator adds as for one written by hand:

`City.make` (a decorator's member) passed and bound by `val`, `Town.of` bound by `val` and by a parameter typed `fn(string) -> Town` — `x`, `y`, `<z>`, `<q>`.
